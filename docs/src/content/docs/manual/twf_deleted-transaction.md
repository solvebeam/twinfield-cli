Work with deleted transactions.

```sh
twf deleted-transaction <command> [options]
```

Twinfield keeps a list of the transactions that were deleted in an office: which transaction, when, by whom and why.

`twf deleted-transaction` alone shows the commands of the group.

## Commands

| Command | Description |
|---|---|
| [`twf deleted-transaction list`](/manual/twf_deleted-transaction_list/) | List the deleted transactions |
