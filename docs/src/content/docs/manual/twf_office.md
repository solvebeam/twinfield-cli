Work with offices.

```sh
twf office <command> [options]
```

An office is a company, or administration, in a Twinfield organisation.

`twf office` alone shows the commands of the group.

## Commands

| Command | Description |
|---|---|
| [`twf office list`](/manual/twf_office_list/) | List the offices |
